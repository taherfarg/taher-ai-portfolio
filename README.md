# Taher Farg — AI Engineer Portfolio

Interactive portfolio for Taher Farg Ibrahim, an AI Engineer and Full-Stack AI Developer based in Dubai.

## Highlights

- Production AI and SaaS project archive
- Skills, experience, certifications, and achievements
- GSAP and Framer Motion animations
- Responsive layouts and HLS video backgrounds
- Direct WhatsApp and email contact actions

## Stack

React, TypeScript, Vite, Tailwind CSS, GSAP, Framer Motion, and hls.js.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
